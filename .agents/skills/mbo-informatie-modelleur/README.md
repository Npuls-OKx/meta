# Skill: MBO informatie modelleur

Skill voor het modelleren van het **concept-informatiemodel** van mbo-onderwijs binnen het OKx OEAPI consumer-profiel: gefaseerde, geneste onderwijsspecificaties in ASCII-boomvorm, met Nederlandse concept-attributen en keuzedelen als zelfstandig programma. Substap (gegevensanalyse → berichtspecificatie) van de [AMIGO-aanpak](../amigo-aanpak/SKILL.md). De vaardigheid zelf is gedefinieerd in [`SKILL.md`](SKILL.md).
