# MOKA-koppelvlakspecificaties (OKE)

Koppelvlakspecificaties voor het OKE-subdomein, opgesteld volgens het **MOKA-format** (de MORA-koppelvlakaanpak). Elke koppelvlakuitwerking staat in een eigen submap. Het generieke sjabloon staat in [`moka-koppelvlakspecificaties/Template/`](../../moka-koppelvlakspecificaties/Template/).
