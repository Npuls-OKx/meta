# Architectuur

De **architectuurkern** van OKx-meta: het ArchiMate-model, **architectuurbesluiten (ADR's)**, onderbouwende domein- en architectuurdocumentatie, **meeting-notulen** en traceerbare **agent-artifacten**. Hier landt de richting die de koppelvlakuitwerkingen in de rest van de repo stuurt.
