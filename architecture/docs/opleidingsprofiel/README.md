# Landelijke opleidingsprofielen

Landelijke opleidingsprofielen uit het hoger beroepsonderwijs die als **domeinvoorbeeld** dienen in OKx-uitwerkingen, naast de [kwalificatiedossiers](../kwalificatiedossier/README.md) uit het mbo. Samen laten zij zien hoe de twee sectoren hun kader opbouwen en waar de vertaling naar de leeruitkomst aangrijpt.

Een opleidingsprofiel is een **sectorafspraak** van de Vereniging Hogescholen, geen wet. De eindkwalificaties zelf legt de instelling vast in haar onderwijs- en examenregeling, op grond van WHW artikel 7.13. Dat is het structurele verschil met het mbo, waar het kwalificatiedossier landelijk en wettelijk is vastgesteld.

Zie [meta #345](https://github.com/Npuls-OKx/meta/issues/345) voor de mapping tussen beide kaders.
