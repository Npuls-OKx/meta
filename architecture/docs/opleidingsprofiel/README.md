# Landelijke opleidingsprofielen

Landelijke opleidingsprofielen uit het hoger beroepsonderwijs die als **domeinvoorbeeld** dienen in OKx-uitwerkingen, naast de [kwalificatiedossiers](../kwalificatiedossier/README.md) uit het mbo. Elk kader kent zijn eigen opbouw, en die worden hier niet op elkaar gelegd: een tabel die een kerntaak naast een competentie zet suggereert een gelijkwaardigheid die er niet is. Wat beide kaders wel delen is de uitgang, want beide vertalen naar leeruitkomsten.

Een opleidingsprofiel is een **sectorafspraak** van de Vereniging Hogescholen, geen wet. De eindkwalificaties zelf legt de instelling vast in haar onderwijs- en examenregeling, op grond van WHW artikel 7.13. Dat is het structurele verschil met het mbo, waar het kwalificatiedossier landelijk en wettelijk is vastgesteld.
