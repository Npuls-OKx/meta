# Requirementsboom: verhuisd naar Public

De requirementsboom leeft sinds 28 augustus 2026 in Npuls-OKx/Public onder [Referentiemateriaal/requirementsboom](https://github.com/Npuls-OKx/Public/blob/dev/Referentiemateriaal/requirementsboom/README.md), naast de koppelvlakspecificaties die de stories aanwijzen. Achtergrond: het geamendeerde [ADR 0025](https://github.com/Npuls-OKx/Public/blob/dev/Referentiemateriaal/adr/0025-requirementsboom-als-koppeling-business-techniek.md) en de overhevelings-PR ([Npuls-OKx/Public#55](https://github.com/Npuls-OKx/Public/pull/55)).

Doorontwikkeling gebeurt daar, onder de milestone [Requirementsboom doorontwikkelen](https://github.com/Npuls-OKx/Public/milestone/3); de navigatie wordt er bewaakt door `scripts/validate-requirementsboom-navigatie.py` in de CI.

Deze map bevat geen inhoud meer. Wijzig hier niets; nieuwe boom-issues en PR's horen op Public.
