# Specificaties

Kaderstellende documentatie voor OKx-**specificaties** op profielniveau. Elke specificatie staat in een eigen submap met haar eigen documenten en beeldmateriaal.

Submappen:

- [`okx-oeapi-consumer-profiel/`](okx-oeapi-consumer-profiel/): het OKx OEAPI consumer-profiel, met de leerroutes en persona's (Jochem, Larissa, Linda).
- [`student-keuze/`](student-keuze/): [keuze-requirements](student-keuze/keuze-requirements.md) (eisen R1-R17 voor alle keuzes rond onderwijsspecificaties, met scenario-figuren) en [regelset-payload](student-keuze/regelset-payload.md) (concept-JSON voor regelsets met benoemde bereiken, herleidbaar naar de requirements).
