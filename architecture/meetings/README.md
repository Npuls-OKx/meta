## Meetings: notulen en transcript

In deze map leggen we meetings vast zodat het werk federatief en asynchroon door kan ontwikkelen.
Dit is de **enige** plek voor meetings: kernteam-, kerngroep-, SI- en leveranciersafstemmingen staan hier naast elkaar.

Structuur — één map per meeting, **datum vooraan**:

```
[YYYYMMDD]_[meetingnaam]/
  summary.md      # samenvatting / notulen
  transcript.md   # letterlijk transcript (optioneel)
```

Afspraak:

- **Datum vooraan (`YYYYMMDD_`)** zodat de map chronologisch sorteert.
- Alleen letters, cijfers en underscores in de meetingnaam — geen spaties, apostrofs, komma's of `&`.
- Notulen zijn de ingang voor follow-up (issues, ADR's, PR's).
- Notulen linken altijd naar relevante issues/ADR's/OKx docs.
- Het **transcript** is de primaire bron; de **samenvatting** is een hulpmiddel en kan
  interpretatiefouten bevatten (o.a. verkeerd toegewezen sprekers). Zie
  [`doc/Privacy-meetings-en-transcriptie.md`](../../doc/Privacy-meetings-en-transcriptie.md).
