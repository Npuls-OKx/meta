# MOKA-koppelvlakspecificaties (sjabloon)

Het **generieke MOKA-sjabloon** en bijbehorende instructies voor het opstellen van koppelvlakspecificaties binnen OKx (volgens de MORA-koppelvlakaanpak). Domeinspecifieke uitwerkingen staan elders in de repo (bijvoorbeeld onder [`OKE/`](../OKE/README.md)).
