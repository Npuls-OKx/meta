# OKx-richtlijnen (MOKA)

De richtlijnen voor koppelvlakspecificaties binnen OKx, opgesteld vanuit MOKA volgens de MORA-koppelvlakaanpak, versie v01-09-25. Ze beschrijven de initiatie, de werkwijze en de eisen aan een specificatie, en gelden naast het [generieke sjabloon](../Template/README.md) in deze map.
