# Screenshots

Afbeeldingen die je in een presentatie toont: schermafdrukken van een specificatie, een diagram uit het ArchiMate-model, een stuk payload.

Verwijs ernaar met een pad vanaf de webroot, dus zonder `public/`:

```html
<img src="/shots/mijn-afbeelding.png" />
```

`voorbeeld.png` is een lege placeholder zodat `_template.md` zonder aanpassingen bouwt. Vervang die verwijzing door je eigen afbeelding, of haal de screenshotslide weg als je er geen hebt.
